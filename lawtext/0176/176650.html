الجامعة اللبنانية

مركز المعلوماتية القانونية

منح وضع الادخال المؤقت عن اطارات المطاط ومحركات السيارات وصناديق الاوتوبوسات والشاحنات والصناديق المبردة وآلات التبريد وآلات الرفع (قلابات ) وعلب تعديل السرعة للسيارات (اكوسة) مع توابعها للمقطورات

فهرس القانون
  • المواد (1-4)

المواد

المادة 1

مادة 1:يمنح وضع الادخال المؤقت عن: 1- اطارات المطاط ( البند 40/11 ), 2- محركات السيارات ( 84/6/31 ), 3- صناديق الاتوبيسات والشاحنات ( البند الجزئي 87/6/12 ), 4- الصناديق المبردة ( 84/15/19 ), 5- الات التبريد ( 84/15/19 ), 6- الات الرفع ( قلابات ) ( البند الجزئي 84/22/42 ), 7- علب تعديل السرعة للسيارات ( البند الجزئي 87/6/31 ), 8- الزجاج المأمون للسيارات ( البند 70/8 ), 9- محاور ( اكوسة ) مع توابعها للمقطوعات ( البند الجزئي 84/63/29 ),الداخلة في صناعة هياكل السيارات وتجهيزها.

المادة 2

مادة 2: يخضع هذا الوضع للاحكام القانونية والنظامية النافذة وتحدد ادارة الجمارك الشروط المناسبة لمراقبته.

المادة 3

مادة 3: تستفيد من هذا الوضع المصانع المقبولة لدى ادارة الجمارك.

المادة 4

مادة 4: ينشر هذا الامر في الجريدة الرسمية ويبلغ حيث تدعو الحاجة.

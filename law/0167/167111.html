النظام المالي للمؤسسات العامة التي تتولى ادارة المستشفيات العامة

نوع النص: مرسوم |  رقم 1587 تاريخ: 25/04/1984

  • استعراض

الفهرس

  • الباب الاول : : احكام عامة (1 - 6)
  • الباب الثاني : : اعداد الموازنة وتصديقها (7 - 7)
    • الفصل الاول : : النفقات (8 - 11)
    • الفصل الثاني : : الواردات (12 - 13)
  • الباب الثالث : : تنفيذ الموازنة (14 - 58)
    • الفصل الاول : : احكام عامة (14 - 15)
    • الفصل الثاني : : تنفيذ الواردات (16 - 21)
    • الفصل الثالث : : تنفيذ النفقات (22 - 22)
      • اولا : عقد النفقة : (23 - 31)
      • ثانيا : تصفية النفقة : (32 - 34)
      • ثالثا : صرف النفقة : (35 - 41)
      • رابعا : دفع النفقة : (42 - 47)
    • الفصل الرابع : : سلفات الخزينة (48 - 58)
  • الباب الرابع : : ادارة اموال المؤسسة واصول مسك حساباتها (59 - 88)
    • الفصل الاول : : ادارة اموال المؤسسة (59 - 73)
      • اولا -موجبات المحتسب المركزي والمحتسبين المحليين : (59 - 67)
      • ثانيا - موجبات امناء الصناديق : (68 - 73)
    • الفصل الثاني : : اصول مسك حسابات المؤسسة (74 - 88)
      • اولا - حسابات الاموال : (74 - 83)
      • ثانيا - محاسبة المواد : (84 - 88)

حول الموقع

انشىء مركز الدراسات والأبحاث في المعلوماتية القانونية (المعروف بمركز المعلوماتية القانونية)، في العام 1986 كوحدة جامعية مستقلة. وذلك بالمرسوم رقم 3144 تاريخ 11/4/1986 المعدل بالمرسوم رقم 4166 تاريخ 16/9/1987. في العام 1993 تحول المركز إلى فرع من فروع كلية الحقوق والعلوم السياسية والإدارية وذلك بموجب المرسوم رقم 4141 تاريخ 13/10/1993.

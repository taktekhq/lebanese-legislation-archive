ان رئيس الجمهورية اللبنانية،
بناء على الدستور اللبناني،
بناء على القانون الصادر بتاريخ 12 كانون الاول 1958،
بناء على اقتراح وزير الداخلية،
وبعد موافقة مجلس الوزراء،
يرسم ما يأتي:

الفهرس

  • الباب الاول : : احكام اولية (1 - 6)
  • الباب الثاني : : القانون الخاص بالموظفين غير المفوضين (7 - 16)
    • الفصل الاول : : (7 - 8)
    • الفصل الثاني : : في التعيين وشروط القبول (9 - 14)
    • الفصل الثالث : : الترقية (15 - 15)
    • الفصل الرابع : : تجديد عقد الخدمة (16 - 16)
  • الباب الثالث : : القانون الخاص بالمفوضين (17 - 24)
    • الفصل الاول : : سلسلة الرتب (17 - 18)
    • الفصل الثاني : : تعيين المفوضين (19 - 22)
    • الفصل الثالث : : الترفيع في ملاك المفوضين (23 - 23)
    • الفصل الرابع : : اوضاع مفوضي الامن العام (24 - 24)
  • الباب الرابع : : احكام خاصة بالاختصاصيين (25 - 26)
  • الباب الخامس : : احكام مشتركة لجميع الموظفين (27 - 33)
    • الفصل الاول : : (27 - 27)
    • الفصل الثاني : : المجلس التأديبي (28 - 30)
    • الفصل الثالث : : النقل وتبادل المركز (31 - 32)
    • الفصل الرابع : : في المعالجات الطبية (33 - 33)
  • الباب السادس : : احكام ادارية (34 - 49)
    • الفصل الاول : : احكام عامة (34 - 35)
    • الفصل الثاني : : الرواتب وملحقاتها (36 - 37)
    • الفصل الثالث : : معاش التقاعد (38 - 38)
    • الفصل الرابع : : لجان التحقيق الصحي (39 - 39)
    • الفصل الخامس : : الرواتب وملحقاتها (40 - 43)
    • الفصل السادس : : احكام انتقالية (44 - 49)

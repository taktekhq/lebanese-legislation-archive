نظام الكتاب العدل ورسوم كتابة العدل

نوع النص: قانون |  رقم 337 تاريخ: 08/06/1994

  • استعراض
  • PDF
  • طباعة

اقر مجلس النواب,
وينشر رئيس الجمهورية القانون التالي نصه:

الفهرس

  • الباب الاول : : تنظيم كتابة العدل (1 - 9)
    • الفصل الاول : : احكام عامة (1 - 3)
    • الفصل الثاني : : شروط التعيين (4 - 9)
  • الباب الثاني : : (10 - 16)
    • الفصل الاول : : الاجازات والنقل (10 - 11)
    • الفصل الثاني : : التفتيش (12 - 14)
    • الفصل الثالث : : التأديب (15 - 15)
    • الفصل الرابع : : الملاحقة القضائية (16 - 16)
  • الباب الثالث : : دوائر كتابة العدل (17 - 17)
  • الباب الرابع : : صندوق التعاضد (18 - 21)
  • الباب الخامس : : اصول ممارسة كتابة العدل (22 - 39)
    • الفصل الاول : : اختصاص الكاتب العدل (22 - 23)
    • الفصل الثاني : : واجبات الكاتب العدل (24 - 32)
    • الفصل الثالث : : الرسوم والاتعاب (33 - 36)
    • الفصل الرابع : : المحظورات (37 - 39)
  • الباب السادس : : احكام خاصة وانتقالية (40 - 44)
  • الباب السابع : : مجلس الكتاب العدل (45 - 51)
    • الفصل الاول : : انشاء المجلس ومهامه (45 - 46)
    • الفصل الثاني : : تنظيم وادارة المجلس (47 - 51)
      • اولا : الجمعية العامة : (47 - 47)
      • ثانيا : مكتب المجلس : (48 - 51)

حول الموقع

انشىء مركز الدراسات والأبحاث في المعلوماتية القانونية (المعروف بمركز المعلوماتية القانونية)، في العام 1986 كوحدة جامعية مستقلة. وذلك بالمرسوم رقم 3144 تاريخ 11/4/1986 المعدل بالمرسوم رقم 4166 تاريخ 16/9/1987. في العام 1993 تحول المركز إلى فرع من فروع كلية الحقوق والعلوم السياسية والإدارية وذلك بموجب المرسوم رقم 4141 تاريخ 13/10/1993.

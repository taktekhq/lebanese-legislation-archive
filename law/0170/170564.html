الفهرس

  • مواد اصدار : (1 - 2)
  • الباب الاول : : انشاء الشركة نظامها القانوني - تسميتها - موضوعها - مدتها - مركزها الرئيسي (1 - 6)
  • الباب الثاني : : رأسمال الشركة الاكتتاب به, زيادته (7 - 14)
  • الباب الثالث : : موارد المصرف (15 - 17)
  • الباب الرابع : : العمليات المالية (18 - 24)
  • الباب الخامس : : اداء الخدمات (25 - 28)
  • الباب السادس : : مجلس الادارة (29 - 41)
  • الباب السابع : : رئيس مجلس الادارة (42 - 47)
  • الباب الثامن : : مفوض الحكومة ومفوضو المراقبة والمراقب المالي (48 - 51)
  • الباب التاسع : : الجمعيات العمومية (52 - 63)
  • الباب العاشر : : الحسابات (64 - 68)
  • الباب الحادي عشر : : حل الشركة وتصفيتها (69 - 72)
  • الباب الثاني عشر : : المنازعات (73 - 74)
  • الباب الثالث عشر : : احكام متنوعة (75 - 76)
  • الباب الرابع عشر : : تأسيس الشركة (77 - 77)
  • الباب الخامس عشر : : في النشر والتسجيل (78 - 79)

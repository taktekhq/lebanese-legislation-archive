النظام الداخلي للجنة مراقبة هيئات الضمان

نوع النص: قرار |  رقم 5 تاريخ: 18/06/2009

  • استعراض
  • PDF
  • طباعة

إن وزير الاقتصاد والتجارة،
بناء على المرسوم رقم 18 تاريخ 11/7/2008 (تشكيل الحكومة)،
بناء على قانون تنظيم هيئات الضمان المنفذ بالمرسوم رقم 9812 تاريخ 4/5/1968 المعدل.
بالقانون رقم 94 تاريخ 18/6/1999 وبالقانون رقم 55 تاريخ 27/12/2008، ولا سيما المادة 47 منه،
وبعد استشارة مجلس شورى الدولة (الرأي رقم 242/2008 ـ 2009 تاريخ 28/05/2009)،
يقرر ما يأتي:

الفهرس

  • المواد : (1 - 2)
  • الباب الاول : : احكام عامة (3 - 11)
    • الفصل الاول : : الهيكلية التنظيمية للجنة مراقبة هيئات الضمان. (3 - 3)
    • الفصل الثاني : : الصلاحيات والمهام الرقابية لرئيس اللجنة (4 - 4)
    • الفصل الثالث : : الصلاحيات والمهام الإدارية والمالية لرئيس اللجنة (5 - 5)
    • الفصل الرابع : : صلاحيات ومهام رؤساء وحدات اللجنة (6 - 6)
    • الفصل الخامس : : صلاحيات ومهام وحدات اللجنة (7 - 10)
    • الفصل السادس : : شروط تعيين رؤساء الوحدات (11 - 11)
  • الباب الثاني : : نظام العاملين في اللجنة (12 - 43)
    • الفصل الاول : : احكام عامة (12 - 14)
    • الفصل الثاني : : شروط الاستخدام (15 - 17)
    • الفصل الثالث : : واجبات المستخدمين والأعمال المحظرة عليهم (18 - 19)
    • الفصل الرابع : : أجور المستخدمين وتعويضاتهم (20 - 29)
    • الفصل الخامس : : الترقية والترفيع (30 - 31)
    • الفصل السادس : : الاجازات (32 - 36)
    • الفصل السابع : : النقل الداخلي (37 - 37)
    • الفصل الثامن : : التأديب (38 - 40)
    • الفصل التاسع : : احكام مختلفة (41 - 43)
  • الباب الثالث : : احكام مالية (44 - 48)

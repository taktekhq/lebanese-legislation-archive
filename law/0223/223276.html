النظام المالي للهيئة العامة للمنطقة الاقتصادية الخاصة في طرابلس

نوع النص: مرسوم |  رقم 2222 تاريخ: 11/06/2009

  • استعراض
  • PDF
  • طباعة

ان رئيس الجمهورية،
بناء على الدستور،
بناء على القانون رقم 18 تاريخ 5/9/2008 (انشاء المنطقة الاقتصادية الخاصة في طرابلس) لا سيما المادة الخامسة منه،
بناء على اقتراح رئيس مجلس الوزراء،
وبعد استشارة مجلس شورى الدولة (الرأي رقم 80/2008-2009 تاريخ 19/1/2009)،
وبعد موافقة مجلس الوزراء بتاريخ 2/4/2009،
يرسم ما يأتي:

الفهرس

  • الباب الاول : : احكام عامة (1 - 4)
  • الباب الثاني : : اعداد الموازنة واقرارها وتصديقها (5 - 7)
    • الفصل الاول : : مضمون الموازنة (8 - 11)
      • القسم الاول : : الواردات (12 - 13)
      • القسم الثاني : : النفقات (14 - 23)
  • الباب الثالث : : تنفيذ الموازنة (24 - 33)
    • الفصل الاول : : تنفيذ الواردات (24 - 32)
    • الفصل الثاني : : تنفيذ النفقات (33 - 33)
      • القسم الاول : : عقد النفقة ومراقبته (34 - 47)
      • القسم الثاني : : تصفية النفقة (48 - 52)
      • القسم الثالث : : صرف النفقة (53 - 61)
      • القسم الرابع : : دفع النفقة (62 - 65)
      • القسم الخامس : : تأدية النفقات دون حوالة دفع مسبقة (66 - 67)
        • 1- السلفات الدائمة : (68 - 79)
        • 2 - السلفات الطارئة : (80 - 82)
        • 3 - احكام مشتركة بين السلفات الدائمة والسلفات الطا : (83 - 86)
      • القسم السادس : : احكام مختلفة (87 - 95)
  • القسم الرابع : : احكام خاصة بصفقات اللوازم والاشغال والخدمات (96 - 98)
    • النبذة الاولى : : المناقصة العمومية (99 - 115)
    • النبذة الثانية : : المناقصة المحصورة (116 - 116)
    • النبذة الثالثة : : استدراج العروض (117 - 118)
    • النبذة الرابعة : : الاتفاق بالتراضي (119 - 122)
    • النبذة الخامسة : : صفقات الخدمات التقنية (123 - 123)
    • النبذة السادسة : : الصفقات بموجب بيان فاتورة (124 - 124)
    • النبذة السابعة : : الاشغال بالامانة (125 - 126)
  • الباب الرابع : : (127 - 161)
    • الفصل الاول : : المحاسبة (127 - 130)
    • الفصل الثاني : : صلاحيات وموجبات المحتسب (131 - 148)
    • الفصل الثالث : : امين الصندوق (149 - 159)
    • الفصل الرابع : : حسابات الاموال - احكام تتعلق ببعض الحسابات (160 - 160)
    • الفصل الخامس : : محاسبة المواد (161 - 161)
  • الباب الخامس : : احكام ختامية (162 - 166)
  • المواد : (166 - 166)

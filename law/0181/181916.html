النظام المالي للمؤسسات العامة التي تتولى ادارة المستشفيات العامة.

نوع النص: مرسوم |  رقم 12399 تاريخ: 23/06/1998

  • استعراض
  • PDF
  • طباعة

ان رئيس الجمهورية,
بناء على الدستور,
بناء على القانون رقم 544 تاريخ 24/7/1996 المعدل بالقانون رقم 602 تاريخ 28/2/1997 (انشاء مؤسسات عامة لادارة مستشفيات وزارة الصحة العامة),
بناء على المرسوم 4517 تاريخ 13/12/1972 وتعديلاته (النظام العام للمؤسسات العامة),
بناء على اقتراح وزير الصحة العامة,
وبعد استطلاع رأي مجلس شورى الدولة (الرأي رقم 57/97 - 98 تاريخ 23/12/97),
وبعد موافقة مجلس الوزراء في جلسته المنعقدة بتاريخ 3/3/1998,

الفهرس

  • الباب الاول : : احكام عامة (1 - 2)
  • الباب الثاني : : قواعد واصول اعداد وتنفيذ موازنة المؤسسة (3 - 28)
    • الفصل الاول : : اعداد الموازنة (3 - 24)
    • الفصل الثاني : : تنفيذ الموازنة (25 - 28)
      • القسم الاول : : تنفيذ الواردات (25 - 27)
      • القسم الثاني : : تنفيذ النفقات (28 - 28)
        • اولا : عقد النفقة : (29 - 33)
        • رابعا : دفع النفقة : (34 - 44)
        • ثانيا : تصفية النفقة : (37 - 37)
        • ثالثا : صرف النفقة : (42 - 42)
        • خامسا : سلفات الخزينة : (45 - 50)
  • الباب الثالث : : صفقات اللوازم والاشغال والخدمات (51 - 51)
    • الفصل الاول : : المناقصة العمومية (52 - 67)
    • الفصل الثاني : : المناقصة المحصورة (68 - 69)
    • الفصل الثالث : : استدراج العروض (70 - 71)
    • الفصل الرابع : : الاتفاق بالتراضي (72 - 74)
    • الفصل الخامس : : الصفقات بموجب بيان او فاتورة (75 - 75)
  • الباب الرابع : : ادارة الاموال والحسابات (76 - 102)
    • الفصل الاول : : المحاسبة (76 - 91)
    • الفصل الثاني : : ادارة الاموال (92 - 102)

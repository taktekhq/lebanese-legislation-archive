نظام المجمع الاعلى للطائفة الانجيلية في سوريا ولبنان

الفهرس

  • الفصل الاول : : تحديد معاني بعض الكلمات والعبارات الواردة في هذا النظام (1 - 1)
  • الفصل الثاني : : تعريف المجمع الأعلى وغايته ومبادؤه وهيكليته وصلاحياته وواجباته (2 - 5)
  • الفصل الثالث : : الهيئة العامة ممثلو كنائس المجمع الأعلى وطريقة انتخابهم ومؤهلاتهم ومدة خدمتهم وفصلهم وانتخاب من يخلفهم. (6 - 13)
  • الفصل الرابع : : هوية الكنائس التي يحق لها الانضمام إلى عضوية المجمع الأعلى وشروط تلك العضوية وكيفية قبولها، والكنائس المشاركة (14 - 20)
  • الفصل الخامس : اللجنة التنفيذية : (21 - 24)
  • الفصل السادس : : هيئة مكتب المجمع الأعلى وطريقة انتخاب أعضائه ومدة خدمتهم وصلاحياتهم وواجباتهم (25 - 29)
  • الفصل السابع : النصاب والتصويت : (30 - 32)
  • الفصل الثامن : المحاكم الروحية للطائفة الإنجيلية : (33 - 37)
  • الفصل التاسع : : الاتصالات المتبادلة بين المجمع الأعلى والكنائس الإنجيلية (38 - 38)
  • الفصل العاشر :رسم العضوية وإيرادات المجمع الأعلى : (39 - 41)
  • الفصل الحادي عشر : تعديل النظام : (42 - 45)

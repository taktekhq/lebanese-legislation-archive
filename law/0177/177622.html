الفهرس

  • الفصل الاول : : شركات القروض العقارية (1 - 2)
  • الفصل الثاني : : في السندات (3 - 6)
  • الفصل الثالث : : قروض شركات القروض العقارية الى اصحاب الاملاك (7 - 21)
    • القسم الاول : : شروط القرض (7 - 10)
    • القسم الثاني : : تنفيذ الرهونات (11 - 17)
    • القسم الثالث : : الحجز عند تأخر المدين عن الدفع (18 - 20)
    • القسم الرابع : : احكام خصوصية (21 - 21)
  • الفصل الرابع : : العمليات الاخرى التي تقوم بها شركات القروض العقارية (22 - 23)
  • الفصل الخامس : : احكام مختلفة (24 - 24)
  • الفصل السادس : : الاعلان والنشر (25 - 27)
  • الفصل السابع : : العقوبات (28 - 29)

حول الموقع

الفهرس

  • الباب الاول: : احكام عامة (1 - 4)
  • الباب الثاني: : فرع الاعداد (5 - 9)
    • الفصل الاول: : الدرجة الخاصة العليا (10 - 10)
      • الدرجة العليا : (11 - 12)
        • النبذة 1: : شروط الدخول (13 - 24)
        • النبذة 2: : التعليم في الدرجة الخاصة العليا وفي الدرجة الخاصة (25 - 26)
        • النبذة 3 : : التعيين بعد التخرج (27 - 28)
    • الفصل الثاني : : الدرجة الوسطى (29 - 37)
      • النبذة 1: : شروط الدخول (29 - 34)
      • النبذة 2: : التعليم في الدرجة الوسطى (35 - 36)
      • النبذة 3 : : التعيين بعد التخرج (37 - 37)
    • الفصل الثالث: : احكام مشتركة بين درجات الاعداد (38 - 39)
  • الباب الثالث: : فرع التدريب (40 - 42)
    • الفصل الاول: : دورة الدراسات الادارية العليا (للفئتين الاولى والثانية) (43 - 49)
    • الفصل الثاني : : دورة التدريب العليا (للفئة الثالثة) (50 - 52)
    • الفصل الثالث: : دورة التدريب الوسطى (للفئة الرابعة) (53 - 54)
    • الفصل الرابع: : احكام مشتركة بين دورات التدريب الثلاث (55 - 56)
  • الباب الرابع: : احكام عامة مشتركة بين فرعي الاعداد والتدريب (57 - 61)
  • الباب الخامس: : الدورات الخاصة للدراسات الدولية (62 - 66)

حول الموقع

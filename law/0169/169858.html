النظام المالي لشركة ادارة واستثمار مرفأ بيروت

نوع النص: قرار |  رقم 11 تاريخ: 04/03/1988

  • استعراض
  • PDF
  • طباعة

ان المدير العام للاستثمار,
بناء على المرسوم رقم 150 تاريخ 10/5/1977 (تعيين المدير العام),
بناء على المادة 16 من الاتفاق المعقود بين الدولة وشركة مرفأ وحواصل مرفأ بيروت تاريخ 13/4/1960 والمصدق بقانون 31/5/1960,
بناء على كتاب شركة ادارة واستثمار مرفأ بيروت رقم 16/ م ب تاريخ 2/3/1988,
يقرر ما يأتي:

الفهرس

  • مواد اصدار : (1 - 2)
  • الباب الاول: : (1 - 4)
    • الفصل الاول: : أحكام عامة (1 - 4)
  • الباب الثاني: : (5 - 51)
    • الفصل الاول: : اعداد الموازنة (5 - 8)
    • الفصل الثاني: : مضمون الموازنة (9 - 18)
      • القسم الأول: : النفقات (9 - 15)
      • القسم الثاني: : الواردات (16 - 18)
    • الفصل الثالث: : تنفيذ الموازنة (19 - 51)
      • القسم الأول: : الواردات (19 - 22)
      • القسم الثاني: : النفقات (23 - 46)
        • النبذة الاولى: : عفد النفقات (23 - 26)
        • النبذة الثانية: : صرف النففة (27 - 33)
        • النبذة الثالثة: : دفع النفقة (34 - 35)
        • النبذة الرابعة: : السلفات (36 - 46)
      • القسم الثالث: : أحكام مختلفة (47 - 51)
  • الباب الثالث: : أحكام خاصة بنفقات اللوازم والاشغال والخدمات (52 - 52)
    • الفصل الاول: : المناقصة العمومية (53 - 77)
    • الفصل الثاني: : المناقصات المحصورة (78 - 79)
    • الفصل الثالث: : استدراج العروض (80 - 81)
    • الفصل الرابع: : الاتفاق بالتراضي (82 - 83)
    • الفصل الخامس: : صفقات الخدمات التقنية (84 - 84)
    • الفصل السادس: : الصفقات بموجب بيان او فاتورة (85 - 85)
    • الفصل السابع: : الاشغال بالامانة (86 - 87)
    • الفصل الثامن: : تقديم العروض وجلسات المناقصات (88 - 102)
  • الباب الرابع: : محاسبة الشركة (103 - 143)
    • الفصل الاول: : موجبات المحاسب (103 - 106)
    • الفصل الثاني: : مسؤولية رئيس فرع المحاسبة (107 - 114)
    • الفصل الثالث: : امناء الصناديق (115 - 121)
    • الفصل الرابع: : حسابات الاموال (122 - 143)
      • القسم الأول: : احكام عامة (122 - 126)
      • القسم الثاني: : احكام تتعلق ببعض الحسابات (127 - 133)
        • اولا- : التأمينات والكفالات (127 - 128)
        • ثانيا": : سلفات الصندوق (129 - 133)
      • القسم الخامس: : محاسبة المواد (134 - 143)

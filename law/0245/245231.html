الفهرس

  • الباب الاول : : انشاء الشركة, نوعها,اسمها,موضوعها مركزها, مدتها (1 - 5)
  • مواد اصدار : (1 - 6)
  • الباب الثاني : : رأسمال الشركة (6 - 8)
  • الباب الثالث : : الاسهم والسندات (9 - 16)
  • الباب الرابع : : إدارة الشركة (17 - 24)
  • الباب الخامس : : مراقبة الشركة (25 - 28)
  • الباب السادس : : الجمعيات العمومية (29 - 40)
  • الباب السابع : : سنة الشركة, الجردة والميزانية،توزيع الأرباح (41 - 45)
  • الباب الثامن : : حل الشركة وتصفيتها (46 - 48)
  • الباب التاسع : : المنازعات (49 - 50)
  • الباب العاشر : : احكام مختلفة (51 - 53)
  • المواد : (53 - 53)

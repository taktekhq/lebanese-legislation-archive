النظام المالي للمؤسسة العامة التي تتولى ادارة مستشفى بيروت الحكومي الجامعي

نوع النص: مرسوم |  رقم 7517 تاريخ: 02/03/2002

  • استعراض
  • PDF
  • طباعة

ان رئيس الجمهورية,
بناء على الدستور,
بناء على القانون رقم 544 تاريخ 24/07/1996 المعدل بالقانون رقم 602 تاريخ 28/02/1997 (انشاء مؤسسات عامة لادارة مستشفيات وزارة الصحة العامة),
بناء على المرسوم 4517 تاريخ 13/12/1972 وتعديلاته (النظام العام للمؤسسات العامة),
بناء على اقتراح وزيري المالية والصحة العامة,
وبعد استشارة مجلس شورى الدولة (رأي رقم 54/2001-2002 تاريخ 04/12/2001),
وبعد موافقة مجلس الوزراء في جلسته المنعقدة بتاريخ 09/01/2002,
يرسم ما يأتي:

الفهرس

  • الباب الاول : : احكام عامة (1 - 8)
  • الباب الثاني : : اعداد الموازنة واقرارها وتصديقها (9 - 22)
    • الفصل الاول : : احكام عامة (9 - 10)
    • الفصل الثاني : : النفقات (11 - 16)
      • الجزء الاول : الموازنة التشغيلية : (11 - 15)
      • الجزء الثاني : موازنة المشاريع (مشروع المؤسسة) : (16 - 16)
    • الفصل الثالث : : الواردات (17 - 22)
      • الجزء الاول : الموازنة العادية التشغيلية : (17 - 18)
      • الجزء الثاني : موازنة المشاريع (مشروع المؤسسة) : (19 - 22)
  • الباب الثالث : : تنفيذ الموازنة (23 - 64)
    • الفصل الاول : : تنفيذ الواردات (23 - 28)
    • الفصل الثاني : : تنفيذ النفقات (29 - 29)
      • القسم الاول : : عقد النفقة (30 - 38)
      • القسم الثاني : : تصفية النفقة (39 - 43)
      • القسم الثالث : : صرف النفقة (44 - 50)
      • القسم الرابع : : دفع النفقة (51 - 51)
      • القسم الخامس : : تأدية النفقة بدون حوالة مسبقة- سلفات طارئة وسلفات دائمة (52 - 58)
      • القسم السادس : : احكام عامة (59 - 63)
    • الفصل الثالث : : احكام خاصة بنفقات الاشغال واللوازم والخدمات (64 - 64)
      • القسم الاول : : احكام خاصة متعلقة بصفقات الاشغال واللوازم والخدمات (65 - 68)
        • البند الاول : : المناقصة العمومية (69 - 84)
        • البند الثاني : : المناقصة المحصورة (85 - 86)
        • البند الثالث : : استدراج العروض (87 - 89)
        • البند الرابع : : الاتفاق بالتراضي (90 - 92)
        • البند الخامس : : الصفقات بموجب بيان او فاتورة (93 - 93)
        • البند السادس : : الاشغال بالامانة (94 - 94)
  • الباب الرابع : : محاسبة المؤسسة (95 - 116)
    • الفصل الاول : : صلاحيات المدير المالي (95 - 98)
    • الفصل الثاني : : مسؤوليات المدير المالي (99 - 104)
    • الفصل الثالث : : أمين الصندوق (105 - 107)
    • الفصل الرابع : : حسابات الاموال (108 - 112)
    • الفصل الخامس : : محاسبة المواد (113 - 116)
  • الباب الخامس : : احكام ختامية (117 - 117)

حول الموقع

انشىء مركز الدراسات والأبحاث في المعلوماتية القانونية (المعروف بمركز المعلوماتية القانونية)، في العام 1986 كوحدة جامعية مستقلة. وذلك بالمرسوم رقم 3144 تاريخ 11/4/1986 المعدل بالمرسوم رقم 4166 تاريخ 16/9/1987. في العام 1993 تحول المركز إلى فرع من فروع كلية الحقوق والعلوم السياسية والإدارية وذلك بموجب المرسوم رقم 4141 تاريخ 13/10/1993.

الفهرس

  • الباب الاول: : احكام عامة (1 - 8)
  • الباب الثاني: : اعداد الموازنة واقرارها وتصديقها (9 - 23)
    • الفصل الاول: : احكام عامة (9 - 11)
    • الفصل الثاني : : النفقات (12 - 20)
      • القسم الأول: : الموازنة العادية (12 - 18)
      • القسم الثاني: : موازنة تنفيذ الخطة العامة والعمليات (19 - 20)
    • الفصل الثالث: : الواردات (21 - 23)
  • الباب الثالث: : تنفيذ الموازنة (24 - 91)
    • الفصل الاول: : تنفيذ الواردات (24 - 33)
      • القسم الأول: : احكام عامة (24 - 30)
      • القسم الثاني: : احكام خاصة بقبول الهبات والتبرعات والمساعدات وبيع اموال المجلس (31 - 33)
    • الفصل الثاني : : تنفيذ النفقات (34 - 34)
      • القسم الأول: : عقد النفقة (35 - 45)
      • القسم الثاني: : تصفية النفقة (46 - 50)
      • القسم الثالث: : صرف النفقة (51 - 59)
      • القسم الرابع: : دفع النفقة (60 - 63)
      • القسم الخامس: : تأدية النفقات بدون حوالة مسبقة سلفات الموازنة العادية احكام عامة (64 - 66)
        • النبذة الاولى: : السلفات الدائمة (67 - 75)
        • النبذة الثانية: : السلفات الطارئة (76 - 78)
        • النبذة الثالثة: : احكام مشتركة بين السلفات الدائمة والسلفات الطارئة (79 - 90)
    • الفصل الثالث: : احكام خاصة بنفقات الاشغال والمواد والخدمات (91 - 91)
      • القسم الأول: : صفقات الاشغال والمواد والخدمات احكام عامة (92 - 93)
        • النبذة الاولى: : المناقصات العمومية (94 - 109)
        • النبذة الثانية: : المناقصة المحصورة (110 - 111)
        • النبذة الثالثة: : استدراج العروض (112 - 113)
        • النبذة الرابعة: : الاتفاق بالتراضي (114 - 117)
        • النبذة الخامسة: : صفقات الخدمات (118 - 118)
        • النبذة السادسة: : الصفقات بموجب بيان او فاتورة (119 - 119)
      • القسم الثاني: : الاشغال بالامانة (120 - 123)
  • الباب الرابع: : محاسبة المجلس (124 - 142)
    • الفصل الاول: : احكام عامة (124 - 125)
      • القسم الأول: : صلاحيات رئيس المحاسبة وموجياته (126 - 130)
      • القسم الثاني: : صلاحيات وموجبات رئيس الادارة المالية (131 - 131)
      • القسم الثالث: : صلاحيات امناء الصناديق ومسؤولياتهم (132 - 141)
    • الفصل الثاني : : أحكام تتعلق ببعض الحسابات (142 - 142)
      • اولا- : مال الاحتياط (143 - 145)
      • ثانيا- : الودائع والتأمينات والكفالات (146 - 147)
      • ثالثا": : سلفات الصندوق (148 - 156)

حول الموقع

انشىء مركز الدراسات والأبحاث في المعلوماتية القانونية (المعروف بمركز المعلوماتية القانونية)، في العام 1986 كوحدة جامعية مستقلة. وذلك بالمرسوم رقم 3144 تاريخ 11/4/1986 المعدل بالمرسوم رقم 4166 تاريخ 16/9/1987. في العام 1993 تحول المركز إلى فرع من فروع كلية الحقوق والعلوم السياسية والإدارية وذلك بموجب المرسوم رقم 4141 تاريخ 13/10/1993.

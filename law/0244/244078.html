قانون البلديات

نوع النص: مرسوم إشتراعى |  رقم 118 تاريخ: 30/06/1977

  • استعراض
  • PDF
  • طباعة

ان رئيس  الجمهورية،
بناء على الدستور،
بناء على القانون رقم 2/76 تاريخ 30/12/1976 (منح الحكومة حق اصدار مراسيم اشتراعية)،
وبعد استشارة مجلس  شورى الدولة،
بناء على اقتراح وزير الداخلية،
وبعد موافقة مجلس  الوزراء بتاريخ 27/6/1977،
يرسم ما يأتي:

الفهرس

  • الباب الاول : : البلديات تعريفها انشاؤها (1 - 6)
  • الباب الثاني : : جهاز البلدية (7 - 7)
    • الفصل الاول : : السلطة التقريرية (8 - 25)
      • القسم الاول : : عدد اعضاء المجلس البلدي, مدة ولايته وانتخابه (8 - 21)
      • القسم الثاني : : حل المجلس البلدي واعادة انتخابه (22 - 25)
    • الفصل الثاني : : نظام اعضاء المجلس (26 - 31)
      • القسم الاول : : التمانع وفقدان الاهلية (26 - 29)
      • القسم الثاني : : الاستقالة والتوقيف عن العمل (30 - 31)
    • الفصل الثالث : : سير العمل في المجلس البلدي (32 - 46)
      • القسم الاول : : الدعوة الى اجتماعات المجلس البلدي (32 - 33)
      • القسم الثاني: النصاب والمناقشات : (34 - 39)
      • القسم الثالث: التصويت على المقررات : (40 - 45)
      • القسم الرابع: محاضر الجلسات : (46 - 46)
    • الفصل الرابع : : اختصاص المجلس البلدي (47 - 66)
      • القسم الاول: مدى اختصاصه : (47 - 55)
      • القسم الثاني: الرقابة الادارية على قرارات المجلس ا : (56 - 66)
  • الباب الثالث : : السلطة التنفيذية (67 - 79)
    • الفصل الاول : : تعريفها وانتخابها (67 - 73)
    • الفصل الثاني : : اختصاص رئيس السلطة التنفيذية (74 - 79)
  • الباب الرابع : : احكام مختلفة (80 - 140)
    • الفصل الاول : : التنظيم الاداري (80 - 85)
    • الفصل الثاني : : مالية البلديات (86 - 90)
    • الفصل الثالث : : الموجه البلدي (91 - 94)
    • الفصل الرابع : : المراقب العام (95 - 99)
    • الفصل الخامس : : الدعاوى (100 - 102)
    • الفصل السادس : : الملاحقات التأديبية والجزائية (103 - 113)
    • الفصل السابع : : اتحاد البلديات (114 - 134)
      • القسم الاول: تعريفه - تشكيله - ولايته : (114 - 117)
      • القسم الثاني: جهاز الاتحاد : (118 - 125)
      • القسم الثالث : اختصاص مجلس الاتحاد : (126 - 129)
      • القسم الرابع: رئاسة مجلس الاتحاد : (130 - 132)
      • القسم الخامس: مالية الاتحاد : (133 - 134)
    • الفصل الثامن : : احكام عامة (135 - 140)

حول الموقع

انشىء مركز الدراسات والأبحاث في المعلوماتية القانونية (المعروف بمركز المعلوماتية القانونية)، في العام 1986 كوحدة جامعية مستقلة. وذلك بالمرسوم رقم 3144 تاريخ 11/4/1986 المعدل بالمرسوم رقم 4166 تاريخ 16/9/1987. في العام 1993 تحول المركز إلى فرع من فروع كلية الحقوق والعلوم السياسية والإدارية وذلك بموجب المرسوم رقم 4141 تاريخ 13/10/1993.

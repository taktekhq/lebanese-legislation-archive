النظام الداخلي للمجلس الاقتصادي والاجتماعي

ان رئيس الجمهورية,
بناء على الدستور,
بناء على القانون رقم 389 تاريخ 12/01/1995المعدل بموجب القانون رقم 533 تاريخ 24/07/1996 (انشاء المجلس الاقتصادي والاجتماعي),

الفهرس

  • الباب الاول : : احكام عامة (1 - 2)
  • الباب الثاني : : انتخاب اعضاء مكتب المجلس وصلحيات المكتب والرئيس (3 - 22)
    • الفصل الاول : : الدعوة للنتخابات - العملية النتخابية (3 - 8)
    • الفصل الثاني : : انتخاب الرئيس ونائب الرئيس، جلسات المكتب، صلاحيات المكتب، صلاحيات الرئيس المدير العام، الاشراف على السجلات (9 - 22)
  • الباب الثالث : : اللجان (23 - 34)
    • الفصل الاول : : تأليف اللجان (23 - 28)
    • الفصل الثاني : : اعمال اللجان (29 - 34)
  • الباب الرابع : : اعمال المجلس، الهيئة العامة (35 - 50)
    • الفصل الاول : : جلسات الهيئة العامة -المناقشات- القرارات (35 - 49)
    • الفصل الثاني : : الانضباط والمسلكية (50 - 50)
  • الباب الخامس : : مالية المجلس (51 - 52)
    • الفصل الاول : : الموازنة (51 - 51)
    • الفصل الثاني : : المساعدات والمساهمات العينية والتقنية والنقدية والهبات والتبرعات (52 - 52)
  • الباب السادس : : النشر والتوجيه (53 - 54)
    • الفصل الاول : : المنشورات -المكتبة -المحاضرات (53 - 54)
  • الباب السابع : : الاتفاقات والمعاهدات (55 - 55)
  • الباب الثامن : : احكام متفرقة (56 - 57)
  • الباب التاسع : : تعديل النظام (58 - 59)
